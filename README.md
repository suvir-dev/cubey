# CUBEY

A 3D obstacle dodging game built using the Unity Engine and compiled for web via webGL. You control a red cube sliding along a path with grey obstacles to dodge!

## Play live in the browser
You can play the game directly on your web browser here:
https://suvir-dev.github.io/cubey/
*PC Only*

## Game features
* 3 levels increasing in difficulty
* Physics based motion and sliding
* Falling obstacles from level 2 onwards

## Tech Stack and Implementation
* Game engine: Unity
* Language: C#
* Deployment: WebGL & GitHub Pages

## Controls
Use the left and right arrow keys to move the cube

*Note: This repository contains the final build deployed for the web. The original project assets and environment files are kept in a separate development directory.*
