# CUBEY

A 3D obstacle dodging game built using the Unity Engine and compiled for web via webGL

## Play live in the browser
You can play the game directly on your web browser here:
https://suvir-dev.github.io/cubey/

## Game features
* 3 levels increasing in difficulty
* Physics based motion and sliding
* Falling obstacles from level 2 onwards

## Tech Stack and Implementation
* Game engine: Unity
* Language: C#
* Deployment: WebGL & GitHub Pages

## Controls
Use the left and right arrow keys to move the cube
